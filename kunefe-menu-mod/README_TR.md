KÜNEFE MENÜ MODU
HUD: FPS, ping, koordinat, yön, saat, zırh ve tuş göstergesi modülleri (ESC > HUD Düzenle ile sürükle-bırak ve aç/kapat).
ESC menüsünde sağda oyuncunun 3D modeli ve altında "Özelleştir" butonu çıkar. Butona basınca KP bakiyesi,
sahip olunan kozmetikler ve mağaza listesi görünür; "Kozmetik Menüsünü Aç" UltraCosmetics'in /uc menu komutunu çalıştırır.
(Şapka / omuz hayvanı çizimini UltraCosmetics yapar, bu mod sadece ESC arayüzüdür.)

1) Bu klasördeki dosyaları GitHub deposunun ANA dizinine yükle (klasör yok).
   build-mod.yml için dosya adına ".github/workflows/build-mod.yml" yazıp "Create new file" ile içeriği yapıştır.
2) Actions > "Kunefe Menu Mod" > Run workflow.
3) Biten çalışmadan "kunefe-menu" artifact'ını indir; içindeki kunefe-menu.jar'ı siteye
   https://kunefecraft.com.tr/kunefe-menu.jar olarak yükle. Launcher otomatik indirir.
